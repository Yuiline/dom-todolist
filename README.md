# 与 yuiline 的时光 ~（v0.2）

一个自学前端的大学生的练习项目：用**原生 JavaScript** 写的一个"和角色相处"的小界面 ——
背景是循环播放的视频，左上角有菜单，可以打开待办清单、听音乐、看自己的好感度和金币、
去商店买东西。没有框架、没有构建工具、零依赖。

## 为什么做这个

上一个项目是个 galgame（恋爱游戏），写着写着发现后端的东西越来越多 ——
存档、账号、剧情分支的服务端逻辑 —— 慢慢偏离了我当时想学的方向，所以先搁置了。

这个项目算是回到前端本身：从 DOM 最基础的操作开始，一路做到能写出一个有交互、
有状态、能存档的小应用。下一步打算把剧情加回来。

## 现在能做什么（v0.2）

**待办清单**（点左上角菜单里的「待办事项」）

- 添加待办：点「添加」，或在输入框里按回车
- 空输入校验：为空或只有空格时提示「请先输入内容」
- 标记完成：点待办文字切换删除线，再点一次取消
- 删除单条 / 一键清空
- 实时统计「共 X 项，完成 Y 项」
- 用**事件委托**实现：只给列表挂一个监听，条目再多也不用重新绑定

**音乐系统**（播放 / 切歌 / 暂停 三个图标）

- 两首歌循环切换，最后一首的下一首自动回到第一首
- 播放 / 暂停切换，播完可以手动切歌
- **可拖动的进度条**：点任意位置跳转，也能按住圆点拖
- 左右显示当前时间和总时长

**时钟**（屏幕上方）

- 显示系统时间，每秒刷新，等宽数字不会左右抖

**好感度 / 金币**（点「好感度」）

- 挂机每 2 分钟 +1 好感 +1 金币
- 好感度上限 1000，金币无上限
- 数据存在浏览器本地（`localStorage`），关掉再打开还在

**商店**（点「商店」）

| 商品 | 价格 | 效果 |
| --- | --- | --- |
| 可乐 | 5 金币 | 好感 +1 |
| 毛绒抱枕 | 20 金币 | 好感 +5 |
| 自助餐券 | 120 金币 | 好感 +30 |
| Switch 游戏机 | 500 金币 | 好感 +200 |

- 金币不够会提示还差多少；好感度满了会拦住，不会白花金币

**设置**（点「设置」）

- 询问是否需要保存，确认后把当前数值写进本地存档

## 技术栈

**原生实现，零依赖。**

- **HTML5**：语义化标签、`id` / `class`、`<video>` 与 `<audio>`
- **CSS3**
  - Flex 布局、`position: fixed` 固定定位、`z-index` 层级
  - `transition` 过渡动画（淡入、位移）、`:nth-child()` 做依次出现的层次感
  - `backdrop-filter`（面板背后的模糊）、`linear-gradient`、`box-shadow` 发光
  - 类名切换控制状态（`.open` / `.done`）
- **JavaScript（ES6+）**
  - 变量与函数：`const` / `let`、函数声明、箭头函数、回调函数、闭包
  - DOM：`getElementById`、`createElement`、`appendChild`、`remove`、`closest`、`children`
  - 事件：`addEventListener`、事件对象 `e`（`e.target`、`e.key`）、事件委托
  - 指针事件：`pointerdown` / `pointermove` / `pointerup` + `setPointerCapture`（拖动进度条）
  - 媒体：`new Audio()`、`play()` / `pause()`、`currentTime`、`duration`、`timeupdate`
  - 时间：`new Date()`、`padStart()` 补零、`setInterval()`
  - 数据：对象数组描述商品表、`forEach` 循环生成界面
  - 存储：`localStorage` + `JSON.stringify` / `JSON.parse`，并用 `try / catch` 兜底
- **运行环境**：现代浏览器（Chrome / Edge 等），双击 HTML 文件即可运行
- **开发工具**：VS Code、浏览器开发者工具（Console / Elements / Application）
- **版本控制**：Git + GitHub

后端、数据库、npm 依赖 —— 目前都没有，是刻意保持的纯前端项目。

## 怎么运行

双击 `18-综合练习一-待办清单.html` 就能打开。建议用 Chrome / Edge，按 `F12` 可以看控制台。

**操作**：左上角那个箭头是菜单，点一下展开四个图标 —— 待办事项 / 好感度 / 商店 / 设置。
音乐控件和进度条在画面中下方。

**清档**：F12 → Application → Local Storage → 找到 `yuiline_save` 删掉即可。
