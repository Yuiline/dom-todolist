# 待办清单 TodoList（v0.1）

一个自学前端的大学生的练习项目：用**原生 JavaScript** 从零写的待办清单。
没有框架、没有构建工具、没有任何依赖，所有代码都在一个 HTML 文件里。

## 为什么做这个

上一个项目是个 galgame（恋爱游戏），写着写着发现后端的东西越来越多 ——
存档、账号、剧情分支的服务端逻辑 —— 慢慢偏离了我当时想学的方向，所以先搁置了。

这个项目算是回到前端本身：从 DOM 最基础的操作开始，一路做到能写出一个完整能用的小应用。
代码是自己一行行敲的，走过的弯路也留在了提交记录里。

## v0.1 实现了什么

- **添加待办**：点「添加」按钮，或直接在输入框里按回车
- **空输入校验**：输入为空、或者只打了空格时提示「请先输入内容」，不会添加空条目
- **标记完成**：点待办文字切换删除线和灰底，再点一次取消
- **删除单条**：点每条右侧的「删除」
- **实时统计**：「共 X 项，完成 Y 项」，任何增删改之后都会自动刷新
- **一键清空**：点「全部清空」，列表和统计一起归零

实现上用到了**事件委托**：只给 `<ul>` 挂一个点击监听，用 `e.target.closest("li")`
判断点到了哪一条。所以不管列表里有多少条、以后再加多少条，都不用重新绑定事件。

## 技术栈

**原生实现，零依赖。**

- **HTML5**：语义化标签（`ul` / `li` / `input` / `button` / `span`）、`id` 与 `class` 属性
- **CSS3**：Flex 布局（让「删除」靠右）、用类名切换状态（`.done` 表示已完成）、
  删除线、颜色与间距、`cursor: pointer` 交互提示
- **JavaScript（ES6+）**
  - 变量与函数：`const` / `let`、函数声明、回调函数
  - DOM 查询：`getElementById`、`querySelector`、`querySelectorAll`
  - DOM 操作：`textContent`、`createElement`、`appendChild`、`remove`、`closest`、`children`
  - 状态与样式：`classList.toggle()`、`className`
  - 事件系统：`addEventListener`、事件对象 `e`（`e.target`）、`e.key === "Enter"`、**事件委托**
  - 字符串方法：`trim()`（判空）
- **运行环境**：现代浏览器（Chrome / Edge 等），双击 HTML 文件即可运行
- **开发工具**：VS Code、浏览器开发者工具（Console / Elements）
- **版本控制**：Git + GitHub

后端、数据库、npm 依赖 —— 这一版全都没有，是刻意保持的纯前端项目。

## 怎么运行

双击 `18-综合练习一-待办清单.html`，浏览器就会打开这个待办清单，直接用即可。

按 `F12` 打开开发者工具，切到 Console 可以看到脚本的输出和报错。
